# 0.2.4-c.1（定制分支）

基于上游 `dsh-deepseek-usage-panel` 0.2.3 修改，仓库名 `dsh-deepseek-usage-panel-c`。
包名与 DSH 插件 ID 保持 `dsh-deepseek-usage-panel`，可直接替换原版。

## 新增

- **峰谷价提示**：胶囊第三列与展开窗时段条显示当前「峰价 / 谷价」以及距下次切换的倒计时。峰价红色、谷价绿色。
  - 规则：北京时间周一至周五（中国法定节假日除外）09:00–12:00、14:00–18:00 为峰价；其余时间（含周末与法定节假日全天）为谷价，谷价为峰价 5 折。
  - 内置 2026 年法定节假日表；2027 年安排公布后需更新 `client.js` 中的 `CN_HOLIDAYS` / `CN_HOLIDAY_YEARS`。
- **今日消费**：悬浮胶囊第二列由「今日 Token」改为「今日消费」，使用余额观测账本口径（余额下降累计），显示 `¥x.xx`。
- **今日 Token 明细**：展开窗新增明细卡，展示缓存命中输入、缓存未命中输入、输出（含推理）、合计，以及响应次数与缓存命中率。
- 展开窗新增时段条；会话 Token 保留在统计卡中。

## 说明

- 峰谷倒计时每秒刷新，到点自动切换；计算使用固定 UTC+8，不依赖本机时区。
- 今日消费不是 token × 单价估算，余额接口有轮询间隔，数字可能略有滞后。
- 今日 Token 为本地观测值，不是 DeepSeek 平台账单。
